# ข้อจำกัดที่ยังเหลือ

1. ยังไม่ได้เชื่อม Google Sheets ของบริษัทจริง เพราะไม่มี Credentials และ Spreadsheet ที่ได้รับอนุญาต ทดสอบได้เฉพาะการตรวจการตั้งค่า เส้นทาง API และกรณียังไม่มี Key
2. ทดสอบบน Linux ด้วย Node 24.19.0 ไม่ได้เปิดบน Windows/macOS จริง โค้ดและคำสั่งใช้รูปแบบข้ามระบบและไม่มี native SQLite module ที่ต้อง Compile แต่ต้องทดสอบบนเครื่องผู้ใช้ตามคู่มืออีกครั้ง
3. ทดสอบหน้าจอด้วย React Testing Library และ jsdom ซึ่งตรวจการกด/ข้อมูลได้ ไม่ได้เป็นการตรวจภาพจริงใน Chrome/Safari ยังไม่ได้ยืนยันความเหมือนภาพอ้างอิงหรือ Responsive ด้วยเบราว์เซอร์จริง มี CSS สำหรับจอ 1600, 1200, 900 และ 640 px พร้อมตารางเลื่อนแนวนอน
4. ไม่มี Login/สิทธิ์หลายระดับ ไม่มีการรับรองตัวตนผู้กรอกชื่อยืนยัน และไม่ได้ให้บริการข้ามเครือข่าย หากใช้ร่วมกันหลายคนต้องพัฒนาส่วนนี้เพิ่มกับ IT
5. Google Sheets และไฟล์นำเข้าเป็น snapshot ที่ได้รับตามรอบ ไม่ใช่ SAP Real-time ข้อมูลที่ต้นทางยังไม่ Export มา ระบบจะยังไม่ทราบ
6. ไม่อ่าน LINE โดยตรง ไม่ส่งข้อความอัตโนมัติ Copy ข้อความแล้วพนักงานนำไปส่งเอง
7. ไม่เปิด WO ใน SAP ไม่ตรวจว่าเลข WO มีอยู่จริงโดยเรียก SAP ใช้หลักฐาน wo_verified + reference จากผู้ดูแลข้อมูลหรือการยืนยันด้วยคนเท่านั้น
8. ต้นทางต้องมี Invoice และ item_ref ที่คงเดิม ถ้ามีเพียง SAP NO. จะยังนำเข้ามาจับคู่โดยปลอดภัยไม่ได้ ต้องเพิ่มข้อมูลอ้างอิงก่อน
9. หนึ่งรายการอ้างอิงติดตามหนึ่ง WO ที่ต้องเปิด การติดตามหลาย Model ต้องแยกรายการอ้างอิง และยอดการ์ดนับรายการติดตาม ไม่ใช่จำนวนสินค้ารหัสไม่ซ้ำ
10. ปฏิเสธ WO Number ซ้ำหลายรายการ หากกระบวนการจริงอนุญาต WO หนึ่งเลขหลายบรรทัด ต้องปรับความสัมพันธ์พร้อมหลักฐานก่อนใช้กรณีนั้น
11. สำหรับผล QC / WO รองรับ CSV UTF-8 / XLSX ตามแม่แบบ 22 คอลัมน์ ไม่รองรับการจับคู่คอลัมน์อัตโนมัติ ไฟล์ .xls ไฟล์มีรหัสผ่าน หรือสูตรในช่องข้อมูล ควร Paste values ก่อนนำเข้า
12. นำเข้าไม่เกิน 10 MB / 10,000 รายการต่อครั้ง ไม่ได้ Load test ข้อมูลระดับแสนรายการ ฟิลเตอร์ฝั่งหน้าจออ่านรายการทั้งหมดของโหมดนั้น
13. ไม่มีการลบรายการที่หายไปจากต้นทางอัตโนมัติ และไม่มี UI ลบ Invoice เพื่อป้องกันข้อมูลประวัติหาย ข้อมูลเปลี่ยนหลังการยืนยันจะต้องตรวจใหม่แม้เป็นการเปลี่ยนช่องที่ไม่กระทบผล QC
14. Sync ทำตามผู้ใช้กดและยืนยัน Preview ไม่มี Scheduler อัตโนมัติ Preview อยู่ในหน่วยความจำและหายหลัง Restart
15. วันรอเป็นวันปฏิทินตามประเทศไทย ไม่หักวันหยุด ไม่มี SLA ที่บริษัทรับรอง
16. ชื่อสินค้าและข้อมูลใน Demo/แม่แบบเป็นข้อมูลสมมติ ไม่ใช่ข้อมูลบริษัท ไม่มี AI และไม่มีค่าบริการ Gemini ในเวอร์ชันนี้

17. เพิ่มอัปโหลด Packing List PDF: ไม่เกิน 10 MB / 50 หน้า / 1,000 รายการ อ่าน Text PDF ด้วยหัวตารางที่รู้จัก ไม่ใช่ AI/OCR ครอบคลุมทุกรูปแบบ ภาพสแกนหรือส่วนที่อ่านไม่ครบต้องกรอก/แก้เองและตรวจจำนวนรายการทั้งหมดก่อนยืนยัน PDF ไฟล์ติดรหัสผ่านต้องปลดรหัสก่อน
18. PDF ใช้เพิ่มรายการตั้งต้น ไม่อ่านผล QC / เลข WO จาก PL และไม่เก็บไฟล์ PDF ต้นฉบับ SAP PO. ที่อ่านได้เก็บในหมายเหตุต้นทางของรายการใหม่ ร่าง PDF หายเมื่อเปลี่ยนหน้า/โหมดหรือ Restart และ Token หมดอายุใน 20 นาที
19. การอัปเดต QC/WO จาก Sheets ต้องใช้ Invoice + item_ref ตรงกับ PDF หาก SAP NO. เดิมมี Ref. ต่างกัน ระบบบล็อก PDF จนผู้ใช้จับคู่ Ref. หรือยืนยันว่าเป็นรายการแยก การแก้ Description เดิมทำให้การยืนยันเดิมต้องตรวจใหม่ตามกฎเดิม

ไม่มีการ Deploy หรือเผยแพร่เว็บไซต์ในการส่งมอบครั้งนี้ ZIP ไม่มี Credentials ไม่มีข้อมูล PL เดิมของบริษัท และไม่มีฐานข้อมูลใช้งานจริง
