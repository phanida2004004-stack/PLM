# คู่มือ VS Code สำหรับผู้เริ่มต้น

VS Code คือโปรแกรมเปิดและจัดการโค้ด ส่วน Terminal คือช่องพิมพ์คำสั่งให้เครื่องทำงาน

1. ดาวน์โหลด ZIP แล้วแตกไฟล์ อย่าเปิดใช้งานจากข้างใน ZIP
2. เปิด VS Code > File > Open Folder เลือกโฟลเดอร์ wo-tracking-dashboard หากพบโฟลเดอร์ซ้อน ให้เลือกชั้นที่เห็น package.json
3. เมื่อ VS Code ถามเรื่อง Trust ให้ตรวจว่าเป็นโฟลเดอร์โปรเจกต์ที่ดาวน์โหลดนี้ แล้วอนุญาตเพื่อรันโค้ด
4. เลือก Terminal > New Terminal จะมีช่องคำสั่งด้านล่าง
5. พิมพ์ `node --version` กด Enter ต้องเป็น v24.x หากไม่มี ให้ติดตั้ง Node 24 LTS ก่อน
6. พิมพ์ `npm install` กด Enter รอจนกลับมาที่บรรทัดพิมพ์คำสั่งได้ ขั้นตอนนี้ใช้อินเทอร์เน็ตครั้งแรก
7. พิมพ์ `npm run dev` กด Enter รอบนี้ Terminal จะทำงานค้างไว้ตามปกติ
8. เปิด Chrome หรือ Edge พิมพ์ http://localhost:5173 ที่ช่องที่อยู่ด้านบน
9. เริ่มใน Demo ไม่ต้องแก้โค้ดหรือสร้าง .env ก่อน
10. เมื่อเลิกใช้ กด Ctrl+C ใน Terminal ไม่ใช่ Command+C บน Mac หาก Windows ถาม Terminate batch job ให้พิมพ์ Y แล้ว Enter

เปิดวันถัดไป: เปิดโฟลเดอร์เดิม > Terminal > `npm run dev` ไม่ต้องติดตั้งซ้ำทุกครั้ง ฐานข้อมูลจะอยู่ในโฟลเดอร์ database

ถ้า npm แจ้ง Warning แต่ตามด้วยเว็บเริ่มทำงานได้ ให้ดูต่อว่าเป็น Warning หรือ Error จริง บางแพ็กเกจอาจแสดงข้อความเลิกสนับสนุน dependency ย่อย ให้ส่งข้อความจริงมาวิเคราะห์เมื่อไม่แน่ใจ อย่าลบฐานข้อมูลเพื่อแก้ปัญหาการเปิดเว็บ

Windows ที่บล็อก npm.ps1: เลือก Terminal แบบ Command Prompt หรือใช้ npm.cmd แทน npm ไม่จำเป็นต้องลดนโยบายความปลอดภัยของเครื่อง

การเปิด .env: ใน Explorer ของ VS Code คลิกขวา .env.example > Copy > Paste แล้วเปลี่ยนชื่อไฟล์สำเนาเป็น .env ต้องไม่มี .txt ต่อท้าย ห้ามนำ JSON Key หรือ .env ไปวางใน frontend/src
